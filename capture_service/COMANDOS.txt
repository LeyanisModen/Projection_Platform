===========================================================
COMANDOS MINI-PC MODEN -- INSTALACION INICIAL
===========================================================

Cheatsheet para copiar / pegar en el mini-PC durante la preparacion
inicial. El runbook largo esta en:

  docs/04_minipc_setup.md

Este archivo viaja dentro de capture_service/ y se copia al mini-PC en:

  C:\moden\capture_service\COMANDOS.txt


===========================================================
TECLAS UTILES EN EL PLAYER
===========================================================

Q dos veces  -> cerrar Chrome kiosko desde el player actualizado.
R            -> recargar la app sin cache.
C            -> abrir / cerrar calibracion.
B            -> mostrar / ocultar fondo de cobertura.
V            -> mostrar / ocultar cama de 15.
W            -> mostrar / ocultar cama de 20.


===========================================================
DOCUMENTACION SIN SATURAR INTERNET
===========================================================

Las fotos periodicas se guardan primero en:

  C:\moden\capture_buffer

Se copian a Google Drive desde el viernes 15:30 hasta el lunes 05:00. Drive
permanece cerrado durante produccion y solo abre 03:45-04:45 entre semana para
la actualizacion automatica. Para comprobarlo:

curl.exe http://127.0.0.1:5555/stats

Campos utiles:

  local_buffer_dir      -> carpeta local donde se captura durante el dia
  output_dir            -> carpeta de Drive donde se publica el fin de semana
  sync_window_active    -> true solo dentro de la ventana semanal
  pending_sync_bytes    -> volumen local pendiente / retenido
  last_sync_at          -> ultima copia a Drive
  last_sync_error       -> error si Drive no estaba disponible
  free_disk_bytes       -> espacio libre actual del disco
  documentation_paused_reason -> pausa segura por falta de espacio


===========================================================
VALORES QUE CAMBIAN POR MINI-PC
===========================================================

Reemplaza "fer_g1_mesa1" por el mesa_id real del equipo.

Formato actual:

  <cli>_g<N>_mesa<M>

Ejemplos:

  fer_g1_mesa1
  fer_g1_mesa2
  fer_g1_mesa3
  fer_g2_mesa1

Nombre Windows equivalente:

  fer_g1_mesa1  ->  FER-G1-MESA1
  fer_g1_mesa2  ->  FER-G1-MESA2
  fer_g2_mesa1  ->  FER-G2-MESA1

Reemplaza "D:" por la letra real del pendrive.

Todas las sesiones de PowerShell indicadas aqui son COMO ADMINISTRADOR,
salvo que se diga lo contrario.

===========================================================
PASO 0.5 -- CREAR CUENTA 'moden' SI EL MINI-PC TRAE 'Usuario'
===========================================================

Solo si el mini-PC ya arranca con un usuario preinstalado tipo
"Usuario", "Dell", "Admin", etc.

# --- En la sesion del usuario preinstalado, PowerShell admin ---

$pw = Read-Host "Contrasena para moden" -AsSecureString
New-LocalUser -Name 'moden' -Password $pw -FullName 'Moden' -Description 'Cuenta de produccion' -PasswordNeverExpires
Add-LocalGroupMember -Group 'Administradores' -Member 'moden'

# Si Windows esta en ingles, usa:
# Add-LocalGroupMember -Group 'Administrators' -Member 'moden'

# --- Cerrar sesion del usuario viejo e iniciar sesion como 'moden' ---

net localgroup Administradores

# Borra la cuenta vieja solo despues de entrar como 'moden'.
# Cambia 'Usuario' por el nombre real si era otro.

Remove-LocalUser -Name 'Usuario'
Remove-Item 'C:\Users\Usuario' -Recurse -Force -ErrorAction SilentlyContinue

===========================================================
PASO 2 -- LANZAR INSTALADOR AUTOMATICO
===========================================================

# --- PowerShell admin ---

cd D:\capture_service
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\install-minipc.ps1 -MesaId fer_g1_mesa1 -ModenPassword "Moden1234"

Que hace el instalador:

  - Hardening de Windows.
  - Python, Chrome, Google Drive y Chrome Remote Desktop host.
  - Copia capture_service a C:\moden\capture_service.
  - Crea venv e instala requirements.txt.
  - Crea config.ini con el mesa_id.
  - Aplica branding-wallpaper.jpg como fondo de escritorio.
  - Aplica branding-user.jpg como imagen de usuario Windows.
  - Crea la tarea programada "MODEN Player".
  - Crea la tarea programada "MODEN Auto Update" diaria a las 04:15.
  - Configura auto-login si pasaste -ModenPassword.

Si no quieres auto-login:

.\install-minipc.ps1 -MesaId fer_g1_mesa1


===========================================================
PASO 2A -- ACTUALIZAR UN MINI-PC QUE YA ESTABA CONFIGURADO
===========================================================

Usa esto UNA VEZ para mini-PCs antiguos que ya funcionaban pero necesitan
recibir el capture_service nuevo, start-player.bat nuevo, COMANDOS.txt nuevo
y la tarea programada de auto-actualizacion.

No reinstala apps, no toca Google Drive, no borra el config.ini y no borra
device_token.txt.

IMPORTANTE:

  - Si el mini-PC ya estaba vinculado y Chrome conserva localStorage, NO
    deberia pedir vinculacion otra vez.
  - Tras esta actualizacion, el player nuevo copiara su token al servicio
    local y aparecera:

      C:\moden\capture_service\device_token.txt

  - Si localStorage ya se habia borrado ANTES de actualizar, tocara
    vincular una vez mas desde admin. Despues de eso queda protegido.
  - Despues de instalar esta version, futuras actualizaciones se revisan
    solas desde:

      G:\Mi unidad\MODEN_UPDATE\capture_service

    Solo tienes que reemplazar ahi la carpeta capture_service de la ferralla.

# --- PowerShell admin ---

# Cambia esta ruta si estas actualizando desde pendrive:
# $src = 'D:\capture_service'
$src = 'G:\Mi unidad\MODEN_UPDATE\capture_service'

$mesaId = (
  Select-String -Path 'C:\moden\capture_service\config.ini' -Pattern '^\s*mesa_id\s*=' |
  Select-Object -First 1
).Line -replace '^\s*mesa_id\s*=\s*', ''

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Get-Process -Name python, pythonw, chrome -ErrorAction SilentlyContinue | Stop-Process -Force

cd $src
.\install-minipc.ps1 -MesaId $mesaId -SkipApps -SkipHardening

Start-Process 'C:\moden\capture_service\start-player.bat'

# Comprobaciones.
Start-Sleep -Seconds 10
curl.exe http://127.0.0.1:5555/health
curl.exe http://127.0.0.1:5555/stats
Test-Path 'C:\moden\capture_service\device_token.txt'
Get-ScheduledTask -TaskName 'MODEN Auto Update' | Format-List TaskName,State,Triggers

Si el ultimo comando devuelve False pero el player esta vinculado:

  - pulsa R dentro del player para recargar la app
  - espera 10 segundos
  - vuelve a ejecutar:

Test-Path 'C:\moden\capture_service\device_token.txt'

Si sigue en False, revisa que el archivo copiado sea el capture_service.py
nuevo y que el player cargue desde https://moden.up.railway.app/player.

Forzar una revision de actualizacion desde Drive sin esperar a la noche:

powershell.exe -NoProfile -ExecutionPolicy Bypass -File 'C:\moden\capture_service\update-capture-service.ps1' -Force


===========================================================
PASO 2 BIS -- SI PYTHON NO QUEDA EN PATH
===========================================================

El instalador intenta resolver Python aunque winget no refresque PATH.
Si aun asi falla, suele ser la alias falsa de Microsoft Store.

Apaga las alias:

  Ajustes -> Aplicaciones -> Configuracion avanzada de aplicaciones
  -> Alias de ejecucion de aplicaciones -> apagar python.exe y python3.exe

Luego abre una PowerShell admin nueva y valida:

python --version
where.exe python

Relanza el instalador:

cd D:\capture_service
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\install-minipc.ps1 -MesaId fer_g1_mesa1 -ModenPassword "Moden1234"

PASO 3 -- VERIFICAR BRANDING
===========================================================

El fondo debe verse tras aplicar el instalador o tras reiniciar.

Comprobar que el fondo quedo copiado:

Test-Path 'C:\moden\branding\wallpaper.jpg'

Test-Path 'C:\ProgramData\Microsoft\User Account Pictures\user.jpg'
Test-Path 'C:\ProgramData\Microsoft\User Account Pictures\user-192.png'

Si devuelve True, los archivos estan aplicados.


===========================================================
PASO 4 -- VERIFICAR TAREA PROGRAMADA "MODEN Player"
===========================================================

Get-ScheduledTask -TaskName 'MODEN Player' | Format-List TaskName,State,Triggers

Debe existir con trigger "At logon" / "Al iniciar sesion" para el
usuario moden.

Si no existe, recrearla:

$bat = 'C:\moden\capture_service\start-player.bat'
$action   = New-ScheduledTaskAction -Execute $bat
$trigger  = New-ScheduledTaskTrigger -AtLogOn -User 'moden'
$settings = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries -StartWhenAvailable
Register-ScheduledTask -TaskName 'MODEN Player' -Action $action -Trigger $trigger -Settings $settings -RunLevel Limited -User 'moden' -Force
Remove-Item (Join-Path ([Environment]::GetFolderPath('Startup')) 'Moden Player.lnk') -Force -ErrorAction SilentlyContinue

PASO 6 -- CHROME REMOTE DESKTOP
===========================================================

Abrir Chrome e ir a:

  https://remotedesktop.google.com/access

Activar acceso remoto:

  - Nombre del dispositivo = nombre Windows, por ejemplo FER-G1-MESA1.
  - PIN = la acordada para la fabrica.

Probar desde el portatil antes de entregar.


===========================================================
PASO 7 -- OBSBOT
===========================================================

Instalar OBSBOT WebCam desde el instalador del pendrive.

En OBSBOT:

  - Desactivar auto-sleep / sleep mode.
  - Desactivar tracking / seguimiento.
  - Mover camara al encuadre correcto.
  - Guardar preset si la app lo permite.
  - Cerrar OBSBOT completamente al terminar.

Muy importante:

  Mientras OBSBOT este abierto, Python no puede usar la camara.
